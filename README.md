# Ritu Khuman — Portfolio

A responsive, single-page portfolio site for Ritu Khuman.

## Open
Open `index.html` in any modern web browser. No build tools or install steps are required.

## Personalize
- Replace `khumanritu055@gmail.com` in the page footers and `contact.html` to update Ritu's contact email. The contact form opens a pre-filled message in the visitor's email app.
- On the home page, click the portrait area to choose a photo from your device. The choice is saved in that browser. The included `photo/photo.png` is used as the default image and is shown to every visitor when the site is published with its `photo` folder.
- Update the sample project descriptions and tags with real work and links.
- Update the bio and skills to match current studies and experience.

Google Fonts are loaded when an internet connection is available; system fonts are used as a fallback.

## Add your resume
- Put your resume PDF in the 
esume folder and name it 
esume.pdf. The **View my resume** button on the About page will open it. Replace that file whenever you update your resume.
